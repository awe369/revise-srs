[…] ClozeForge

Cards you make on any website are saved to data/cloze.json in your revise-srs repo and reviewed in the Cloze tab of your Revise app. Usually you only need to paste the token below.

Create the token (one minute)

  1. Open GitHub → Fine-grained token.
  2. Repository access: Only select repositories → pick your repo.
  3. Permissions → Contents: Read and write. Nothing else is needed.
  4. Generate, copy, paste it above.

How to use

  1. Select text on any page → click the […] Cloze button, right-click → Make cloze card, or press Alt+Shift+C.
  2. Click words in the preview to hide them. Each number (c1, c2…) becomes its own review.
  3. Press Ctrl+Enter to save. Review on your site — click a card's source to jump to the exact sentence.

Heads-up: if the repository is public, your cards are public too. Use a private repo for private notes (the review site then needs the token to read them).
