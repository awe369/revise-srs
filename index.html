Connect your GitHub repo

One-time setup, takes ~1 minute.

  1. Open github.com/settings/personal-access-tokens/new
  2. Name: revise · Expiration: pick the longest you're comfortable with
  3. Repository access → Only select repositories → choose this repo
  4. Permissions → Repository → Contents: Read and write
  5. Generate token, copy it, paste below.
Stays only in this browser. Never shared with anyone except GitHub.
